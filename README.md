# atharvamusale.github.io

Personal portfolio and blog, generated by a small Python static-site builder
(Jinja2 + markdown-it + YAML) and deployed to GitHub Pages with GitHub Actions.

## Local development

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python build.py --serve        # http://localhost:8000, rebuilds on save
```

## Layout

| Path | What lives there |
| --- | --- |
| `content/site.yaml` | Profile, highlights, experience, skills, education, links |
| `content/projects/*.md` | Case studies. Front matter drives metrics, tags, stack, and the pipeline diagram |
| `content/posts/YYYY-MM-DD-Title.md` | Blog posts, published at `/YYYY/MM/DD/Title.html` |
| `templates/` | Jinja2 templates |
| `static/` | CSS, JS, images, copied to `/assets/` |
| `build.py` | The generator; output goes to `_site/` |

### Pipeline steps

Each `pipeline` entry in a project takes a `kind` that sets its color:
`agent` (LLM / agent), `deterministic` (plain code), `parallel` (fan-out), or `storage` (state).

## Deployment

Every push to `master` runs `.github/workflows/deploy.yml`, which builds the site and
publishes `_site/`. One-time setup: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
